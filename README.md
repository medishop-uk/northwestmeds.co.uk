# NorthwestMeds static website

Responsive static site built from the supplied NorthwestMeds HTML content. Includes medicine tiers, shared basket, WhatsApp/Telegram checkout, GA4/GTM/GSC tags, canonical metadata, sitemap, robots and legacy URL redirects.

The Apps Script deployment URL must be added to `assets/js/config.js` after deploying `google-apps-script/reviews.gs` from the `northwestmeds-data.xlsx` workbook.
